PENUGASAN REVISI DOSEN — Work4Village (checklist)
Berdasarkan penjelasan dosen di atas. Centang = sudah selesai di sistem.
================================================================================

A. KONSEP & AKTOR
[✓] Modal kerja produktif, bukan bantuan uang tunai pasif
    → Program mikro desa + insentif/upah setelah validasi logbook

[✓] Pekerja miskin TIDAK akses aplikasi (tanpa HP/login)
    → Hanya role admin & pengawas; pekerja = data di tabel workers

[✓] Admin = pemerintah desa / kementerian desa
    → Role admin mengelola profiling, program, inventaris, validasi

[✓] Pengawas = surveyor lapangan yang mewakili pekerja
    → Logbook, distribusi, pelaporan, pemantauan profiling

B. PROFILING (INTI REVISI DOSEN)
[✓] Ganti istilah "data orang miskin" → Profiling
    → Menu "Profiling Keluarga", halaman Profiling & Analisis Kesejahteraan

[✓] Indikator profiling multi-dimensi (bukan sekadar KTP):
    → Pendidikan, frekuensi makan, status gizi, sanitasi, air bersih,
      pendapatan keluarga, kebiasaan, riwayat kesehatan, status rumah

[✓] Acuan indikator Kemensos/BPS (skor vulnerabilitas)
    → ProfilingScorer: 8 indikator, skor 0–30, threshold otomatis

[✓] Threshold survei (100 orang → tidak semua layak program)
    → Skor < 6 = "Tidak Layak Program" (tidak masuk antrean penugasan)
    → Dashboard profiling menampilkan: Layak vs Tidak Layak vs Lulus

[✓] Prioritas penugasan (prioritas tinggi dulu)
    → Skor ≥14 tinggi, 10–13 sedang, 6–9 rendah; urut di daftar pekerja

C. SDG 1, 2, 3
[✓] SDG 1 — Kemiskinan: skor pendapatan per kapita, klasifikasi kesejahteraan
[✓] SDG 2 — Kelaparan: frekuensi makan, status gizi
[✓] SDG 3 — Kesehatan: riwayat penyakit, sanitasi, akses air bersih

D. MATCHING PEKERJAAN
[✓] Penugasan sesuai keahlian profiling (bukan cuma nama)
    → ProfilingScorer::matchScore() + sektor_keahlian di program
    → Form jadwal menampilkan skor & keahlian pekerja

[✓] Pekerja lintas desa (asal desa A, kerja di desa B)
    → Field nama_desa (keluarga) + desa_lokasi (program)
    → Badge "Lintas Desa" di profil pekerja

E. PEMANTAUAN PROGRES & KELULUSAN
[✓] Profiling awal tersimpan (snapshot JSON saat pendaftaran)
[✓] Perbandingan awal vs sekarang di halaman profil pekerja
[✓] Riwayat pemantauan berkala (tabel profiling_histories + profiling_snapshots)
[✓] Skor per dimensi: makan, sanitasi, pendapatan, pendidikan + total_skor
[✓] Upload bukti foto kondisi lapangan saat survei
[✓] Status kesejahteraan: Pending / Sangat Miskin / Rentan Miskin / Lulus/Tidak Layak
[✓] Kolom keahlian_kerja untuk matching pekerjaan
[✓] Daftar diurutkan total_skor tertinggi (prioritas otomatis)
[✓] Tombol Update Profiling (survei ulang) + Tandai Lulus
[✓] Form Alpine.js mempertahankan input saat validasi gagal (old())
[✓] Status "Lulus Program" — slot dialihkan ke calon baru
    → Tombol Lulus di profiling (admin) + catatan snapshot otomatis

    → Belum otomatis; masih manual oleh admin (bisa ditambah rule engine)
